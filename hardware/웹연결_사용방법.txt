ParkingMate 웹 연결 사용 방법

1. 웹 담당자에게 '웹담당자_전달사항.txt'를 보내고 백엔드 주소와 센서 키를 받는다.
2. 노트북 인터넷, STM32 USB, Pico 전원과 기존 2.4GHz 핫스팟을 준비한다.
3. 설정 전환 중에는 센서를 통과하지 않는다.
4. 바탕화면 'ParkingMate 웹 연결' 또는 '웹연결_시작.cmd'를 연다.
5. 서버 주소(/api 제외)와 센서 키를 입력한다.
6. '연결 확인 후 시작'을 누른다.
7. 카운터 화면에서 '웹 전송 모드'와 입구/출구 '연결됨'을 확인한다.
8. 센서 한 번 통과 후 최근 기록에 '서버 확인'이 뜨는지 확인한다.
9. 배포된 웹을 열어 숫자 변화를 확인한다. 웹 자체 갱신 주기만큼 늦게 보일 수 있다.

다음부터는 저장된 두 값을 불러오므로 버튼만 누르면 된다.
설정 창을 닫아도 수신 프로그램은 계속 실행된다. 종료는 카운터의 '수신 프로그램 종료'.

화면 설명
- 큰 숫자 = 이 전송 DB의 현재 표시 세션에서 입차 횟수 - 출차 횟수. 서버의 현재 주차 대수와는 다를 수 있다.
- 서버 확인 = 서버가 새 이벤트 또는 이미 받은 동일 이벤트로 확인했다는 뜻. 웹 화면 갱신은 별도 확인.
- 전송 대기 = 노트북에 보관 중. 인터넷/인증/서버를 확인하면 같은 ID로 다시 보낸다.
- 표시 초기화 = 노트북 표시만 0부터 시작. 서버 대수와 미전송 기록은 바뀌지 않는다.
- 같은 서버로 다시 연결하면 미전송 기록도 이어 보낸다.
- 기존 현장 테스트 기록과 웹 전송 기록은 따로 저장되며, 과거 테스트 기록은 자동 전송하지 않는다.

파일
- 비공개 서버 설정: sensor/runtime/web-connection.json (키가 있으므로 공유하지 않기)
- 전송 기록: sensor/web-runtime/서버별폴더/bridge.sqlite
- 기존 현장 테스트 기록: sensor/field-runtime/bridge.sqlite
- 폴더를 지우거나 옮기지 않아야 재전송과 중복 방지 이력이 유지된다.

실제 서버 연결/실차 정확도는 설정 도구를 만든 것만으로 검증되지 않는다. 서버 인증 확인 후 실제 통과로 웹 담당자와 함께 확인한다.
