# 산천어축제 주차안내 UI 규칙

보는 사람: 화천군 교통 담당 공무원(평가자), 실제 이용자는 50대 이상 운전자.
참고 대상: 도로 주차유도 전광판(PGIS), 공영주차장 안내 앱, 정부 디자인 시스템(KRDS). 마케팅 랜딩페이지가 아님.

## 문구
- 설명문·광고 카피 금지. "어디에 주차할까요?", "~를 드려요!", "여유로운 시작" 같은 말투 쓰지 않음.
- 안내판처럼 명사형·사실형: "임시주차장 현황", "09:30 기준", "남은 자리", "만차", "셔틀 화천체육관".
- 한 줄에 정보 하나. 문장은 꼭 필요할 때만, 짧게.
- 내부 메모(“협의 후 확정”, “추정”)는 방문객 화면 본문에 쓰지 않고 작은 출처 줄이나 `예시` 태그로만.
- 이모지, 느낌표, 영어 슬로건 금지.

## 시각
- 색: 남색 `--navy` 기본, 상태색 여유 초록 / 혼잡 주황 / 만차 빨강 / 정보없음 회색. 상태는 **색 + 글자** 같이 (색약 대응).
- 그라데이션, 그림자 카드, 둥근 큰 일러스트, 장식 아이콘, 3단 '스텝' 박스 금지.
- 표·목록 중심. 행 왼쪽 상태 막대, 오른쪽 큰 숫자(남은 자리). 구분선은 1px.
- 글자: Pretendard. 본문 19px 이상, 핵심 숫자 1.7rem 이상, `font-variant-numeric: tabular-nums`.
- 터치 영역 52px 이상, 입력칸 56px 이상, 차량번호 입력은 크게 가운데.
- 한 화면 한 가지 일: 홈=현황, QR 화면=이 주차장+이용권 발급, 이용권=안내소에 보여줄 화면, 관리=직원 입력.

## 점검 절차 (화면 바꾼 뒤 매번)
1. 백엔드·프론트 실행 후 `python tools/demo_setup.py` 로 토요일 오전 상황 입력.
2. `bash tools/shot.sh / docs/shots/home.png 2000` 등으로 휴대폰 크기 스크린샷을 찍어 직접 본다
   (`/p/wirari`, `/v/<코드>`, `/shuttle`, `/admin`).
3. 아래 질문에 모두 "예"인지 확인:
   - 60대 운전자가 3초 안에 "어디에 대면 되는지" 아는가?
   - 공무원이 보고 "현장에서 쓰는 화면"이라고 느끼는가? (홍보 페이지처럼 보이면 실패)
   - 지어낸 숫자 없이, 모르는 값은 "정보없음/확인 중"으로 보이는가?
   - 390px 폭에서 가로 넘침이 없는가?
4. 화면이 바뀌었으면 Figma 「ParkingMate 프론트 디자인」 파일도 갱신 (`figma-sync` 스킬).
