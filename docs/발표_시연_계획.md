듣는 사람: 화천군청 멘토(교통 담당 포함). 이 프로젝트를 **처음 듣는다** → 1학기 내용부터 짧게.

## 2. 라이브 시연 순서 (1분 30초)
준비물: 노트북(백엔드·프론트·브리지 실행), 센서 키트(입구 A·B), 인쇄한 **QR 안내판**(관리 → QR 안내판 → 인쇄), 시연용 휴대폰, 프로젝터에 노트북 화면.

1. (10초) 프로젝터에 **임시주차장 현황**. "토요일 오전 9시 30분 상황입니다. 가까운 곳은 만차, 위라리 둔치는 남은 자리 312."
2. (20초) 센서 앞에서 손이나 판으로 **A → B 순서로 빔을 가림** → 현황판 위라리 숫자가 줄어드는 걸 보여줌. "차가 들어오면 센서가 세고 바로 반영됩니다."
3. (30초) 휴대폰으로 **QR 안내판을 찍음** → 위라리 둔치 화면 → 차량번호 입력 → **이용권 발급**. 휴대폰 화면을 카메라나 미러링으로 보여줌.
4. (20초) 관리 화면 **이용권 탭** → 번호 입력 → **사용 처리** → 휴대폰 화면이 "사용 완료"로 바뀜. "안내소 직원은 이 화면 하나만 쓰면 됩니다."
5. (10초) 같은 차량번호로 다시 발급 시도 → "이미 받으셨어요" 거부. 끝.

### 시연 전 체크 (발표 30분 전)
```bash
cd backend && ./gradlew bootRun --args='--app.demo-clock=2027-01-16T09:30'
cd frontend && npm run dev
python tools/demo_setup.py
python sensor/bridge.py --serial COM5      # STM32 포트 확인: 장치 관리자
```
- 휴대폰이 노트북 화면에 접속하려면 같은 Wi-Fi + 노트북 IP 주소(`http://192.168.x.x:5173`). 또는 배포 주소(Vercel)로 QR 안내판을 인쇄.
- 관리 화면 키: 로컬은 `dev-admin`.
- 한 번 리허설하고 `rm -rf backend/data` 로 초기화한 다음 다시 `demo_setup.py`.

### 플랜 B (센서·네트워크 문제 시)
- 센서 안 되면: `python sensor/simulate.py --count 5 --fast` 로 입차를 보내서 같은 흐름 진행. "실물 시험 결과는 다음 장에서"라고 말함.
- 인터넷 안 되면: 노트북 한 대에서 전부 로컬로 실행 (휴대폰 대신 노트북 브라우저로 /p/wirari 접속).
- 최악: 미리 찍은 **시연 영상**(1분 30초) 재생. → 월요일까지 촬영해 둘 것.

## 3. 예상 질문과 답 (3분)
| 질문 | 답의 요지 |
|---|---|
| 이용권 예산·종류는 누가 정하나? | 군에서 검토 중인 방안(인터뷰)에 맞춰 만들었고, 종류·수량은 설정값이라 정해지면 바로 바뀝니다. 지금은 예시입니다. |
| QR 사진만 찍어서 집에서 받으면? | 센서가 있는 주차장은 최근 90분 안의 실제 입차 1건당 1장만 발급되고, 차량번호당 하루 1장입니다. 센서 없는 곳은 직원 발급으로 운영합니다. |
| 어르신들은 휴대폰 못 쓰시는데? | 주차장 직원이 차량번호로 대신 발급하는 화면이 있습니다. 화면 글자도 크게, 단계는 차량번호 하나만 입력하게 했습니다. |
| 눈 오면 주차선이 안 보이는데 센서가 맞나? | 센서는 들어오고 나간 대수만 셉니다. 실제로 댈 수 있는 면수는 직원이 "운영 가능 면수"로 바로 고칠 수 있게 했습니다(인터뷰 반영). |
| 겨울 추위에 장비·건전지는? | AA 건전지 전원 + 퓨즈. 영하 시험은 아직 못 했고, 실제 설치 전 확인할 항목으로 정리했습니다. (사실대로) |
| 개인정보(차량번호)는? | 차량번호는 중복 발급 방지에만 쓰고 그날 축제가 끝나면 지워도 되는 구조입니다. 실제 운영 전 보관 기간을 군과 정하겠습니다. |
| 설치비·운영비는? | 시제품 부품비 약 56만 원(차로 2개). 서버는 무료 등급으로 시연 중이고, 실제 운영 시 비용은 별도 산정이 필요합니다. |
| 현장 인력 통제 부담은 줄어드나? | 담당자께서 말씀하신 통제 권한·사고 책임 문제(녹음 20~21분)는 제도 문제라 저희가 풀 수는 없습니다. 다만 막아서 돌려보내는 대신 혜택으로 스스로 가게 하는 방식이라 직원이 차를 직접 막는 상황을 줄이는 쪽입니다. 효과는 아직 측정하지 못했습니다. |
| 기존 방식보다 뭐가 나은가? | 지금은 직원이 무전으로 상황을 공유합니다. 이 화면 하나로 직원·방문객이 같은 정보를 보고, 발급·사용 기록이 남아 효과를 숫자로 볼 수 있습니다. |
