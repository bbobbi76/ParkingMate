# 시연 영상 촬영 계획 (노션 「시연 영상 촬영 계획」과 같은 내용)

1분 30초 영상 하나. 발표 때 라이브 시연이 안 되면 이걸 틀고(플랜 B), 노션·제출용으로도 씁니다.

| 항목 | 내용 |
|---|---|
| 길이 | 1분 30초 |
| 화면 | 휴대폰 세로 화면 녹화 + 센서 실물 장면 |
| 형식 | 1080p · mp4 · `화천주차셔틀안내_시연.mp4` |
| 담당 | 촬영 [ ] · 센서 [박서빈] · 편집 [ ] |

## 1. 찍기 전 준비 (20분)
- [ ] Render 환경 변수: `DEMO_CLOCK=2027-01-16T09:30` · `SHUTTLE_ALWAYS=true` · `ADMIN_OPEN=true` (바꾸면 3~5분 뒤 반영)
- [ ] 서버 깨우기: https://parkingmate-api.onrender.com/api/now
- [ ] 관리 화면 「시연 초기화」 → `python tools/demo_setup.py --api https://parkingmate-api.onrender.com`
- [ ] 휴대폰: 방해 금지, 밝기 최대, 카카오맵 앱 설치
- [ ] 노트북: 센서 브리지 켜기, 관리 화면 열어 두기
- [ ] 센서 키트: 입구 A·B 설치, 가렸을 때 기록 찍히는지 한 번 확인

## 2. 녹화 도구
| 무엇을 | 도구 |
|---|---|
| 휴대폰 화면 | 안드로이드 「화면 녹화」 / 아이폰 「화면 기록」 |
| 노트북 관리 화면 | `Win + Alt + R` (Xbox Game Bar) 또는 OBS |
| 센서 실물 | 다른 휴대폰으로 가로 촬영, 고정 |
| 편집 | Clipchamp 또는 CapCut |

## 3. 장면 순서
| 시간 | 장면 | 할 일 | 자막 |
|---|---|---|---|
| 0:00–0:08 | 시작 | 홈 화면 | 축제 토요일 오전 9시 30분, 가까운 주차장은 만차 |
| 0:08–0:25 | ① 어디에 댈까 | 추천 상자 → [카카오맵 길찾기] → 앱 열림 | 남은 자리 많은 곳을 맨 위에, 길찾기는 버튼 한 번 |
| 0:25–0:45 | ② 센서가 센다 | 평생학습관 주차장 50 → 입구 A→B 가리기 49 → 출구 가리기 50 (실물·화면 나누기) | 차가 들어오면 49, 나가면 50 — 센서가 바로 셉니다 |
| 0:45–1:00 | ③ 셔틀은 어디서 | 위라리 상세: 정류장 지도, 걸어서 3분, 다음 셔틀 | 정류장까지 걸어서 3분, 다음 셔틀은 N분 후 |
| 1:00–1:12 | ④ 버스는 지금 | 셔틀 탭: 지도와 정류장 한 줄에 버스 모양 | 버스가 지금 어디쯤인지 한눈에 |
| 1:12–1:25 | ⑤ 축제장에서 | 축제장 지도(화천천 위 구역) → 현장낚시터 → 요금·길찾기 | 낚시터·체험장·먹거리를 지도로 |
| 1:25–1:30 | 끝 | 주소 | parking-mate.vercel.app |

## 4. 편집·주의
- 자막은 화면 아래 크게, 첫 장면에 "시연용 시각(2027.1.16 토)", 셔틀 장면에 "버스 위치는 시간표 기준 예상값"
- 실제 차량은 번호판·얼굴 흐리게, 안전한 곳에서. 관리자 키·센서 키가 화면에 나오지 않게
- 다 찍으면 노트북·USB·구글 드라이브에 저장, 노션 링크 칸에 붙이기, 촬영 뒤 「시연 초기화」 + `demo_setup.py` 다시
