## 시연 순서 (1분 30초)
1. 홈 추천 상자: "위라리 둔치 312자리 남음 · 셔틀 정류장: 화천체육관" → [카카오맵 길찾기]
2. 입구 센서 가리기 → 홈·관리 화면 위라리 숫자 줄어듦 (출구 가리면 다시 늘어남)
3. 위라리 상세: 셔틀 정류장 지도 · 걸어서 약 3분 · 다음 셔틀 N분 후 · 축제장까지 10분
4. 셔틀 탭: 정류장 한 줄에서 버스 위치
5. 축제장 탭: 안내도에서 현장낚시터 → 요금·길찾기
(시간 남으면) 관리 화면: 운영 가능 면수 줄이기 → 홈 남은 자리·혼잡도 바로 바뀜

## 안 될 때
| 문제 | 대처 |
|---|---|
| 웹이 안 열림 / 느림 | 서버 깨우는 중 → 1분 기다리기. 그래도 안 되면 노트북 로컬 실행 |
| 센서 반응 없음 | `python sensor/simulate.py --api https://parkingmate-api.onrender.com --key "SENSOR_KEY" --count 3 --fast` |
| 지도 안 뜸 | 카카오 콘솔 도메인 확인. 목록·숫자는 지도 없이도 정상 |
| 인터넷 없음 | 노트북 로컬 실행 (README 로컬 실행) 또는 **시연 영상** |
