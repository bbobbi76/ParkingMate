## 시연 순서 (1분 30초)
1. 현황판: "토요일 9시 30분, 가까운 곳 만차, 위라리 둔치 남은 자리"
2. 센서 가리기 → 숫자 줄어듦
3. 휴대폰 QR → 차량번호 → 이용권 발급
4. 관리 화면 이용권 탭 → 번호 입력 → 사용 처리 → 휴대폰 "사용 완료"
5. 같은 차량번호로 다시 → "이미 받으셨어요"

## 안 될 때
| 문제 | 대처 |
|---|---|
| 웹이 안 열림 / 느림 | 서버 깨우는 중 → 1분 기다리기. 그래도 안 되면 노트북 로컬 실행 |
| 센서 반응 없음 | `python sensor/simulate.py --api https://parkingmate-api.onrender.com --key "SENSOR_KEY" --count 3 --fast` |
| 이용권 "입차 확인이 안 됐어요" | 센서 입차를 먼저 1번 → 다시 발급. 또는 관리 화면 **직원 대리 발급** |
| 지도 안 뜸 | 카카오 콘솔 도메인 확인. 목록·숫자는 지도 없이도 정상 |
| 인터넷 없음 | 노트북 로컬 실행 (README 로컬 실행) 또는 **시연 영상** |

## 리허설 후 초기화
- 리허설에 실제 차량을 써도 됨: 센서는 **통과 대수**만 세고, 그 뒤 90분 안에 차량번호를 넣으면 이용권 발급.
- 같은 차량번호는 하루 1장 → 리허설 끝나면 **관리 → 이용권 탭 → 「시연 초기화」** (이용권·센서 기록 삭제, 위라리 차량 수 188로)
- 그다음 `python tools/demo_setup.py --api https://parkingmate-api.onrender.com` 한 번 더 (상태 다시 맞추기)
