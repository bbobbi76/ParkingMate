# 직접 해 주셔야 하는 설정·확인 (2026-11-15)

키와 비밀번호는 채팅에 붙여 넣지 말고, 아래에 적은 파일이나 환경 변수에 직접 넣어 주세요.

## 1. 카카오맵 키 (지도 표시에 꼭 필요)
1. https://developers.kakao.com 에 카카오 계정으로 로그인합니다.
2. 내 애플리케이션 → 애플리케이션 추가하기를 누릅니다. 앱 이름은 예를 들어 `화천축제주차안내`로 합니다.
3. 앱 설정 → 플랫폼 → Web 플랫폼 등록에서 사이트 도메인을 추가합니다.
   - `http://localhost:5173`
   - Vercel 배포 주소는 배포한 뒤에 추가합니다.
4. 제품 설정 → 카카오맵 → 사용 설정을 ON으로 켭니다. 이걸 안 켜면 지도가 안 떠요.
5. 앱 키 2개를 저장합니다.
   - JavaScript 키: `frontend/.env.local` 파일을 새로 만들고 아래 한 줄을 적습니다.
     ```
     VITE_KAKAO_JS_KEY=여기에_JavaScript_키
     ```
   - REST API 키: 주차장 좌표를 카카오 검색으로 보정할 때 씁니다. 잘 보관해 두면 나중에 실행 방법을 알려 드릴게요.

키가 없어도 지도는 OpenStreetMap으로 대신 나와요. 그래도 발표할 때는 카카오맵이 더 익숙해서 좋아요.

## 2. GitHub 저장소
- 새 저장소를 만듭니다. 예: `hwacheon-parking`, Private도 괜찮아요.
- 만들고 나서 주소를 알려 주시면 제가 코드를 올려 둘게요.

## 3. Neon (PostgreSQL DB, 무료, 카드 불필요)
1. https://neon.tech 에 GitHub로 가입합니다.
2. 새 프로젝트를 만들 때 Region은 AWS Asia Pacific (Singapore)로 고릅니다.
3. Connection string을 복사해서 메모장에 보관합니다. Render 배포 때 씁니다.

## 4. Render (백엔드 서버, 무료) / Vercel (웹 화면, 무료)
- https://render.com , https://vercel.com 에 각각 GitHub로 가입만 해 두세요.
- 실제 배포는 저장소를 만든 뒤에 같이 해요.
- Render 무료 서버는 15분 동안 아무도 안 쓰면 잠들어요. 시연 5분 전에 사이트를 한 번 열어서 깨워 두면 됩니다.

## 5. 담당자께 확인할 데이터 (문자나 전화)
- [ ] 임시주차장별 면수. 지금 아는 건 화천초 약 160대, 강 건너 약 500대뿐이에요.
- [ ] "강 건너 약 500대" 부지가 **위라리 둔치 주차장**이 맞는지
- [ ] 무료이용권 종류. 녹음에는 "낚시 제외, 눈썰매 등 체험"으로 나와요.
- [ ] 이용권을 줄 주차장. 지금은 위라리 둔치, 실버복지센터, 구 헌병대 부지로 잡아 둔 팀 제안이에요.
- [ ] 2027 축제 셔틀 정류장별 도착 시각. 지금은 정류장 사이 10분으로 추정해 넣었어요.

## 6. 하드웨어 (센서 연결용)
- STM32는 차가 지나갈 때마다 USB 시리얼로 한 줄씩 보내게 해 주세요. 형식은 `IN` 또는 `OUT`이고 줄 끝에 줄바꿈을 붙여요. 노트북 쪽 브리지 프로그램은 제가 만들게요.
- Pico 2 WH는 Wi-Fi로 노트북의 브리지에 같은 형식으로 보내요. 펌웨어 예시 코드도 드릴게요.
