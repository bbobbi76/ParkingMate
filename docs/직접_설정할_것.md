## 남은 것
### 1. 카카오 개발자 콘솔 (로컬에서도 카카오맵 보려면)
developers.kakao.com → 내 애플리케이션 → 앱 설정 → 플랫폼 → Web 사이트 도메인에 추가
- `http://localhost:5173`
- `http://<내 PC IP>:5173` (같은 와이파이 휴대폰으로 볼 때)

등록 안 하면 로컬에서는 OpenStreetMap 으로 대신 나와요(기능은 같음).

### 2. Render 환경 변수 (발표 전 확인)
Render → parkingmate-api → Environment
| 이름 | 발표 때 | 평소 |
|---|---|---|
| `DEMO_CLOCK` | `2027-01-16T09:30` | 비움(현재 시각) |
| `SHUTTLE_ALWAYS` | `true` | 실제 운영 시 `false` |
| `ADMIN_OPEN` | `true` | `false` |

### 3. 좌표
위라리 둔치 등 일부 주차장은 공식 배치도를 보고 잡은 근사 좌표예요(지도에서 강 쪽으로 조금 치우쳐 보임). 멘토링 때 받는 자료나 현장 확인으로 고칠 예정이에요.
